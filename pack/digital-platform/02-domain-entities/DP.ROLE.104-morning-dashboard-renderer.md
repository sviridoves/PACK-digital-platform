# DP.ROLE.104 — Генератор утреннего дашборда

## Kind / Owner

- **Kind:** специализированный исполнитель (детерминированный скрипт, не LLM-решение — убери скрипт, утренняя сводка не соберётся).
- **Owner Role:** DP.ROLE.001 (IWE Creator) — владелец надсистемы IWE.

## Обязанности

- Прочитать входы DayPlan / WeekPlan / реестр / отчёт о здоровье платформы на текущую дату.
- Собрать HTML-панель с датой в имени и положить в `DS-strategy/current/`.
- Сообщить пилоту путь к панели одной строкой; провал генератора не блокировать Day Open.

## Полномочия

- Чтение файлов планов и реестра.
- Запись одного HTML-файла панели.

## Связи

| Роль | Связь |
|------|-------|
| DP.ROLE.001 (пилот) | получает панель как вход для утреннего взгляда |
| R1 Стратег | планирует день, источник данных для панели |

## Входы / выходы как артефакты

- **Вход:** DayPlan, WeekPlan, WP-REGISTRY, отчёт о здоровье платформы.
- **Выход:** `Dashboard-<дата>.html` (derived, не источник истины).
